# Univalent Foundations Program — Homotopy Type Theory

## Prerequisites
- [[logic-basic]]

## Notes
Authors: the Univalent Foundations Program. Dependent type theory
with the univalence axiom, higher inductive types, and homotopy
theory developed synthetically. Collaborative and informal-rigorous;
free online. Skim for how type theory can serve as foundations,
different from Lean's classical setup.
