# Hubbard & Hubbard, Vector Calculus, Linear Algebra, and Differential Forms

## Prerequisites
- [[analysis-foundations]]

## Notes
Authors: John H. Hubbard, Barbara Burke Hubbard. Multivariable
analysis done properly — linear algebra, inverse and implicit
function theorems, manifolds in Rⁿ, integration, and differential
forms with Stokes's theorem — with motivation, pictures, and a huge
exercise set. The best on-ramp to the differential-geometry track:
forms appear here concretely before [[smooth-manifolds]].
