# Kedlaya, Notes on Class Field Theory

## Prerequisites
- [[algebraic-number-theory]]

## Notes
Author: Kiran Kedlaya (Berkeley 254B, revised 2025). States class
field theory first, proves Kronecker–Weber, then builds group
cohomology and the local and global theory. Deliberately informal —
read it for the overview and the *why* before Milne's proofs.
