# Milne, Algebraic Number Theory (notes)

## Prerequisites
- [[galois-theory]]
- [[commutative-algebra-basic]]

## Notes
Author: J. S. Milne. Dedekind domains, class groups, units,
cyclotomic fields, valuations, local and global fields, in 166 pages
with exercises. Terser than Sutherland; consolidates and sets up
Milne's class field theory notes with the same conventions.
