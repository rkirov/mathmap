# Milne, Class Field Theory (notes)

## Prerequisites
- [[algebraic-number-theory]]

## Notes
Author: J. S. Milne. Local class field theory (Lubin–Tate and
cohomological), global CFT ideal-theoretically and via ideles, the
Brauer group. Exercises with solutions, many historical asides.
Widely used as a course text. Full cohomological proofs after
Childress's gentler first pass.
