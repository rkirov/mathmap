# Sutherland, Number Theory I (MIT 18.785 notes)

## Prerequisites
- [[commutative-algebra-basic]]
- [[galois-theory]]

## Notes
Author: Andrew Sutherland. 28 lectures: absolute values, Dedekind
domains, étale algebras, Frobenius and the Artin map, local fields
and Hensel, different and discriminant, geometry of numbers, units,
zeta and L-functions, class number formula, Kronecker–Weber, class
field theory statements, adeles and ideles. Clean, example-rich, with
11 problem sets. A modern free replacement for Neukirch that runs
straight into class field theory.
