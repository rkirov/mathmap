# Vinogradov, Elements of Number Theory

## Prerequisites
(none)

## Notes
Author: I. M. Vinogradov. Compact classic from the 1930s: divisibility,
congruences, primitive roots, characters. Each chapter is followed by
a large set of problems (with numerical exercises) that carry much of
the content. The Russian problem-driven style applied to elementary
number theory.
